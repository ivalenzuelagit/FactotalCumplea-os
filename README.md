# Cumpleaños Feliz · Factotal

Tarjeta de cumpleaños interactiva inspirada en la pieza gráfica de Factotal: globos verdes con logo, confeti dorado, tipografía elegante y una torta con velas animadas.

## Cómo verla

Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático.

```bash
npx serve .
```

## Interacciones

- Los globos flotan. Haz clic para reventarlos; vuelven a aparecer.
- Las velas parpadean. Puedes apagarlas una a una o con **Soplar las velas**.
- **Encender de nuevo** vuelve a prender todas las velas.
- Confeti dorado y verde en movimiento continuo.

## Personalizar el nombre

Añade el destinatario en la URL:

```
index.html?nombre=Ana
```

## Publicar en GitHub Pages

1. Crea un repositorio y sube estos archivos.
2. En **Settings → Pages**, publica la rama `main` desde la raíz.
3. La tarjeta quedará en `https://tu-usuario.github.io/nombre-del-repo/`.

## Créditos

Diseño basado en la tarjeta corporativa de Factotal. Implementación en HTML, CSS y JavaScript sin dependencias.
